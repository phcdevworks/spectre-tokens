Accessibility Guidelines

✓ Color Contrast

All color combinations in Spectre tokens meet WCAG AA standards for color contrast, ensuring text is readable for users with low vision or color blindness.

✓ Focus Indicators

All interactive elements have clear, visible focus indicators that meet WCAG requirements for keyboard navigation.

✓ Touch Targets

Minimum touch target size of 44×44px ensures interactive elements are accessible on touch devices and for users with motor impairments.

✓ Readable Text

Base font size of 16px and appropriate line heights ensure text is comfortable to read without zooming, especially on mobile devices.
