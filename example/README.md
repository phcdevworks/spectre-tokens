# Spectre Tokens Examples

This directory contains comprehensive examples for all token categories in the Spectre design system.

## Available Examples

### 🎨 [Colors](colors.html)

Complete color palette including:

- Brand colors (50-900 scale)
- Neutral colors
- Semantic colors (success, warning, error, info)
- Surface colors (page, card, input, overlay)

### 📝 [Typography](typography.html)

Font scales, families, and text styles:

- Type scale (xs to 6xl)
- Font families (sans, serif, mono)
- Font weights and line heights

### 📏 [Spacing](spacing.html)

Spacing scale and layout tokens:

- Space tokens (0-96)
- Section padding (sm, md, lg)
- Stack spacing (gap values)
- Layout containers

### 🔲 [Borders & Radii](borders.html)

Border colors, widths, and radii:

- Border radii (none, sm, md, lg, pill)
- Border colors (card, input)
- State borders (focus, success, error)

### ☁️ [Shadows](shadows.html)

Elevation and shadow tokens:

- Shadow scale (none, sm, md, lg)
- CTA button shadow
- Elevation demo with interactive cards

### 🔘 [Buttons](buttons.html)

Button variants with all states:

- Primary, Secondary, Ghost
- Danger, Success, CTA, Accent
- All states: default, hover, active, disabled

### 📋 [Forms](forms.html)

Form input styles and states:

- Text inputs with all states
- Textarea and Select dropdowns
- Checkboxes and Radio buttons
- Valid, invalid, and disabled states

### ⚡ [Animations & Transitions](animations.html)

Motion and animation tokens:

- Fade in/out animations
- Slide up/down
- Scale, bounce, shake, pulse
- Duration tokens (instant to slower)
- Easing functions

### 🧩 [Components](components.html)

Ready-to-use component tokens:

- Badges (neutral, info, success, warning, danger)
- Cards
- Icon boxes
- Testimonials
- Pricing cards
- Rating stars

### ♿ [Accessibility](accessibility.html)

Focus rings, touch targets, and a11y:

- Focus ring styles
- Touch target sizes (WCAG compliance)
- Minimum text sizes
- Opacity tokens
- Color contrast information

## How to View

Open `index.html` in a web browser to navigate through all examples. Each example page includes:

- Visual demonstrations
- Token values (colors, sizes, durations)
- Interactive examples where applicable
- Code snippets and values for reference

## Usage

These examples demonstrate how to use the Spectre design tokens in your projects. Each token value is displayed alongside its visual representation, making it easy to:

1. See all available options
2. Compare different variations
3. Understand the intended use cases
4. Copy token values for implementation

All examples use the exact token values from `tokens/core.json`.
