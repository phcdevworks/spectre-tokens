🧱 HTML Elements

Plain semantic HTML styled from tokens alone

Coverage

Every element in the HTML Living Standard (115) and 14 styleable pseudo-elements are mapped to token roles in element-coverage.json. npm run check:elements keeps that true. This page shows a selection, in light and dark.

Light mode

Edits: removed text added text. Highlight: marked text. Keys: Ctrl + K. Inline code. Proofing: mispeled and a grammar error. Select some text to see the selection colour.

// Syntax highlighting from --sp-code-syntax-*
const total = sum(items, 42) as number
const label = 'Spectre'
